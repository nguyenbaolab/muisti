# USER GUIDE — Muisti

Hướng dẫn ngắn cho người dùng (không cần biết kỹ thuật).

---

## Ôn tập và hình thức hỏi

Trước khi bắt đầu ôn (`/review` hoặc ôn trong một deck), chọn ít nhất **một** hình thức:

1. **Gõ chữ** — hiện nghĩa, bạn gõ từ tiếng Phần Lan.
2. **Trắc nghiệm chọn nghĩa** — hiện từ tiếng Phần, chọn đúng nghĩa trong 4 đáp án.
3. **Trắc nghiệm chọn từ** — hiện nghĩa, chọn đúng từ tiếng Phần trong 4 đáp án.

Nếu bật nhiều hình thức, mỗi câu được chọn ngẫu nhiên; **gõ chữ** xuất hiện thường hơn mỗi loại trắc nghiệm. Nếu bộ từ quá nhỏ (không đủ đáp án nhiễu), trắc nghiệm tự chuyển sang gõ chữ cho câu đó.

### Trong lúc làm bài

Màn hình hiện:

- **Câu hiện tại / tổng** — tổng có thể tăng nếu bạn trả lời sai (từ sai sẽ được hỏi lại).
- **Số đúng** và **số sai**
- **Đồng hồ** thời gian phiên

Các số này cập nhật khi bạn bấm **Tiếp theo** (khi đang xem đáp án thì số chưa đổi).

## Luyện file tự do

Trên trang **Decks**, bấm nút xanh **Luyện file tự do**:

1. Upload file từ vựng (mỗi dòng: `từ_tiếng_Phần;nghĩa`, giống file tạo deck).
2. Chọn số từ muốn luyện và hình thức hỏi.
3. Luyện trong phiên hiện tại.

**Không** lưu vào deck, **không** ảnh hưởng lịch ôn SRS. Đóng trang hoặc xong phiên là hết — chỉ luyện tạm.
