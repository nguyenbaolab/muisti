# Muisti

Web app học từ vựng tiếng Phần Lan theo deck do người dùng tự upload (public hoặc private). Dùng thuật toán SRS (SM-2 rút gọn) để ôn tập; tiến độ ôn riêng từng người. Invite-only, không đăng ký công khai.
